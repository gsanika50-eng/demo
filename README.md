## Calculator Program

A simple CLI calculator program written in Python.

### Usage

```bash
python3 calculator.py <operation> <num1> <num2>
```

#### Supported Operations
- `add` or `+`
- `subtract` or `-`
- `multiply` or `*`
- `divide` or `/`

#### Example
```bash
python3 calculator.py add 10 5
# Output: Result: 15.0
```

### Running Tests

To run the unit tests:

```bash
python3 -m unittest test_calculator.py
```
